# 🛒 ShopApp — Website bán đồ điện tử

Nền tảng thương mại điện tử chuyên bán các sản phẩm điện tử: điện thoại, laptop, phụ kiện công nghệ, thiết bị thông minh... Hỗ trợ đầy đủ quy trình từ duyệt sản phẩm, đặt hàng, thanh toán đến quản trị hệ thống.



## 🛠 Công nghệ sử dụng

 Thành phần | Công nghệ |

| **Backend** | JavaScript(Node.js/Express.js) |
| **Frontend** | ReactJS / JavaScript / TypeScript |
| **Cơ sở dữ liệu** | MySQL |
| **Xác thực** | JWT (JSON Web Token) |
| **Containerization** | Docker, Docker Compose |
| **Quản lý mã nguồn** | Git & GitHub |





 ✨ Chức năng chính

 👤 Phía người dùng
- 🔐 Đăng ký / Đăng nhập (login)
- 🛍️ Xem, tìm kiếm, lọc sản phẩm theo danh mục (category), thương hiệu
- 🛒 Giỏ hàng (cart) — thêm/xóa/cập nhật số lượng sản phẩm
- 📦 Đặt hàng & theo dõi đơn hàng (order)
- 💬 Chat trực tuyến hỗ trợ khách hàng (chat)
- ⭐ Đánh giá & phản hồi sản phẩm (feedback)
- 🎟️ Áp dụng mã giảm giá / voucher
- ⚡ Săn sản phẩm khuyến mãi trong Flash Sale (flashsale)
- 🖼️ Banner quảng cáo trên trang chủ (banner)

 🛠 Phía quản trị
- 📁 Quản lý sản phẩm (product) & danh mục (category)
- 📋 Quản lý đơn hàng (order)
- 🎫 Quản lý voucher / khuyến mãi
- ⚡ Quản lý Flash Sale
- 🖼️ Quản lý banner trang chủ
- 💬 Quản lý phản hồi khách hàng
- ⚙️ Cấu hình hệ thống (setting)
